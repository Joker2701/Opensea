# Запуск Telegram-бота

Бот тільки сканує ринки і шле алерти. Угод сам не відкриває.

## 1. Отримати токен

1. У Telegram написати [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задати ім'я і юзернейм — BotFather видасть токен виду
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

## 2. Запустити

```bash
export SPREADBOT_TG_TOKEN="<токен від BotFather>"
cp config/config.example.yaml config/config.yaml   # один раз, якщо ще нема
python3 -m spreadbot -c config/config.yaml bot
```

Процес має лишатись запущеним (сервер, VPS, `screen`/`tmux`, systemd — на
ваш розсуд). Поки він не запущений — ані сканування, ані команд у Telegram
не буде.

## 3. Прив'язати бота до себе

Напишіть боту в Telegram `/start`. **Перший**, хто це зробить, стає єдиним
власником — усі команди з інших чатів бот мовчки ігнорує. Якщо хочете
закріпити власника заздалегідь (наприклад, при автозапуску без ручного
`/start`): дізнайтесь свій chat_id (наприклад, через [@userinfobot](https://t.me/userinfobot))
і задайте його як змінну оточення:

```bash
export SPREADBOT_TG_CHAT="<ваш chat_id>"
```

## 4. Команди

| Команда | Що робить |
|---|---|
| `/menu` | панель керування з кнопками (капітал, поріг едж, біржі, пауза) |
| `/scan` | просканувати прямо зараз і показати знахідки |
| `/list` | коротко — останні знахідки |
| `/status` | коли сканував востаннє, скільки знайшов, чи на паузі |
| `/pause`, `/resume` | зупинити / відновити автосканування |
| `/help` | список команд |

## 5. Що можна крутити з `/menu` (кнопками, без перезапуску)

* **Капітал на угоду** — крок $1000
* **Мін. едж (сирий і чистий)** — крок 0,5 п.п.
* **Інтервал автосканування** — крок 5 хв
* **Активи** — ETH / BTC
* **Предикт-маркети** — Polymarket / Kalshi
* **Біржі опціонів** — Bybit / Deribit
* **Пауза** — тимчасово зупинити алерти, не зупиняючи процес

Ці налаштування зберігаються в SQLite (`db_path` з конфігу) і мають
пріоритет над `config.yaml` — файл лише задає стартові значення.

## 6. Формат алерту

Кожна знахідка приходить окремим повідомленням — та сама картка, що й у
консолі (`report.opportunity_card`): ринок, ноги позиції, умови A і B з
запасом у доларах, очікувана дохідність. Той самий сигнал повторно не
шлеться, поки не мине `cooldown_minutes` (за замовчуванням 2 години).
